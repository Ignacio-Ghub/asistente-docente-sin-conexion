Cómo funciona el seguimiento

  1. Agregue a sus estudiantes, una sola vez.
  2. Después de cada evaluación, anote cuántas preguntas acertó cada uno y pulse «Guardar resultados».
  3. El asistente le avisa quién necesita refuerzo y guarda el historial de cada estudiante.
